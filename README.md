# Практический бизнес-семинар для предпринимателей

Одностраничный сайт бизнес-семинара в Караганде.

**26 ноября, 18:30 · Назарбаева 37**

Темы: маркетинг, автоматизация заявок и налогообложение 2026 года.

## Запуск

```bash
npm install
npm run dev
```

Сайт откроется на [http://127.0.0.1:8080](http://127.0.0.1:8080).

## Стек

Vue 3 + TypeScript, Vite, Tailwind CSS v4. Публикуется на GitHub Pages при пуше в `main`.

- `src/App.vue` — каркас страницы
- `src/components/` — шапка, первый экран, секции, кнопка записи
- `src/components/HeroScene.vue` + `src/scene/iso.ts` — анимированная изометрическая иллюстрация
- `src/content.ts` — тексты, спикеры, партнёры, ссылка на WhatsApp

## Что внутри

- титульный экран с анимированной иллюстрацией и запись в WhatsApp
- партнёры, дата, адрес и темы
- спикеры и бонус
- кнопки «Записаться» и «Забронировать место» открывают чат WhatsApp

## Безопасность

- **Секреты не хранятся в репозитории.** Переменные окружения — в `.env`
  (игнорируется git), шаблон — в `.env.example`. Переменные `VITE_*` попадают
  в JavaScript сайта и видны всем, поэтому секреты в них класть нельзя.
  Сайт статический и сейчас не использует ни одного секрета.
- **XSS.** Vue экранирует весь выводимый текст; `v-html`/`innerHTML` не
  используются. Боевая сборка добавляет Content-Security-Policy (только
  собственные скрипты, без inline и `eval`) — см. `vite.config.ts`.
- **Ввод.** На сайте нет форм. Единственная настраиваемая ссылка
  (`VITE_WHATSAPP_URL`) принимается только в виде `https://wa.me/<номер>`.
- **Google Apps Script** (`google-apps-script/Code.gs`) проверяет каждое поле,
  защищает таблицу от инъекции формул, ограничивает частоту запросов и не
  раскрывает детали ошибок. Сайт его сейчас не использует — если он не нужен,
  архивируйте развёртывание в Google.
- **Авторизация, база данных, админ-панель** отсутствуют: это публичная
  страница без пользовательских данных.

## Реклама в Meta: пиксель и события

- Пиксель включается, когда задан его ID: для сайта — переменная репозитория
  `META_PIXEL_ID` (Settings → Secrets and variables → Actions → **Variables**),
  локально — `VITE_META_PIXEL_ID` в `.env`. Без ID пиксель не загружается.
- События: `PageView` при открытии страницы и `CompleteRegistration` при
  нажатии любой кнопки записи (переход в WhatsApp). У регистрации есть
  параметры `value: 15000`, `currency: KZT`, `button_location`
  (`header` / `hero` / `results` / `price`) и уникальный `eventID`.
- Conversions API требует секретный токен и сервер. На GitHub Pages сервера
  нет, поэтому CAPI подключается отдельно (например, Cloudflare Worker или
  CAPI Gateway) и должен передавать тот же `eventID` для дедупликации.
  Токен никогда не кладётся в `VITE_`-переменные.

## Яндекс Метрика

- Счётчик `114333673` (вебвизор, карта кликов, точный показатель отказов,
  внешние ссылки) подключается в `src/lib/yandexMetrika.ts` без встроенного
  скрипта — CSP разрешает только `mc.yandex.*` и `yastatic.net`.
- Работает только в собранной версии сайта; `npm run dev` статистику не шлёт.
  Другой счётчик можно задать через `VITE_YANDEX_METRIKA_ID`.
- Клик по любой кнопке записи отправляет цель `registration` с параметром
  `button_location`. В Метрике создайте цель «JavaScript-событие» с
  идентификатором `registration`.

## Google тег (GA4)

- Контейнер `GTM-MTT8BNFQ` (Google Analytics 4, поток `G-ZDRD882N2L`)
  подключается в `src/lib/googleTag.ts` без встроенного скрипта; CSP разрешает
  только `*.googletagmanager.com` и `*.google-analytics.com`.
- Работает только в собранной версии сайта. Другой контейнер —
  `VITE_GOOGLE_TAG_ID`.
- Клик по кнопке записи отправляет событие `generate_lead`
  (`value: 15000`, `currency: KZT`, `button_location`). Отметьте его в GA4 как
  ключевое событие. Теги «Пользовательский HTML» в контейнере работать не
  будут — их блокирует CSP.
